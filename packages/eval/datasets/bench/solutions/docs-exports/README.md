# textkit

Small text helpers.

### `upper`

Upper-cases text. Example: `upper("a")` returns `"A"`.

### `reverse`

Reverses text. Example: `reverse("ab")` returns `"ba"`.

### `words`

Splits text into words. Example: `words("a b")` returns `["a", "b"]`.

### `initials`

Joins the first letters of the words. Example: `initials("Ada Lovelace")` returns `"AL"`.
